# CMS

Админка на Vite.

## Скрипты

В каталоге `cms`:

### `yarn dev`

Запускает dev-сервер на [http://localhost:3000](http://localhost:3000).

### `yarn build`

Проверяет типы и собирает продакшен-сборку в `build`.

### `yarn start`

Отдаёт собранную папку `build` локально на [http://localhost:3000](http://localhost:3000).

### `yarn admin`

Подтягивает репозиторий, ставит зависимости, собирает проект и запускает его: `git pull`, `yarn`, `yarn build`, `yarn start`.
